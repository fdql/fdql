Getting started

Start in mock mode, then connect a Firebase Emulator profile or a production service account when you are ready.

1. Download

  1. Open the latest GitHub release.
  2. Download the package for your OS.
  3. Download the matching SHA256SUMS file and verify the package.

2. Try mock mode

Fresh installs open with demo data. Use it to explore Firestore, Authentication, JavaScript Query, jobs, activity, loading states, empty states, and write confirmations without touching Firebase.

3. Connect local emulators

  1. Open Add account.
  2. Choose Local emulator.
  3. Enter project id, Firestore host, and Auth host.

4. Connect production

Use a service account JSON file only when you intend to work with a real project. Production writes are enabled, so use least-privilege credentials where possible.
