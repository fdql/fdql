Features

Firebase Desk focuses on the admin workflows developers repeat most often.

Firestore

  • Browse root collections in the account tree.
  • Run collection queries with filters, sorting, limits, and pagination.
  • Switch results between table, tree, and JSON views.
  • Edit full document JSON or individual fields.
  • Create documents and run collection import/export/copy/delete jobs.

Authentication

  • List and filter users.
  • Inspect user details and metadata.
  • Review and edit custom claims.

JavaScript Query

  • Run trusted JavaScript against a selected Firebase Admin SDK context.
  • View returned Firestore data with the same result browser.
  • Read script logs and errors without replacing prior result output.

Workspace

  • Use multiple tabs across different accounts.
  • Keep jobs, activity, status, and active project visible.
  • Persist workspace state and UI preferences locally.
