Troubleshooting

Start with mock mode when you need to separate app behavior from Firebase credentials or emulator state.

App will not open

  • Verify the downloaded file with the matching SHA256SUMS file.
  • On macOS, unsigned builds may need Gatekeeper approval.
  • On Windows, SmartScreen may show a warning for unsigned builds.

Project connection fails

  • Check the selected mode: mock, local emulator, or production.
  • For emulators, confirm Firestore and Auth host values match your Firebase Emulator Suite output.
  • For production, confirm the service account has the permissions needed for the action.

Firestore or Auth data looks wrong

  • Refresh the active surface.
  • Check the visible connection label before making writes.
  • Use mock mode to compare the expected UI flow against stable sample data.

Report a bug

Open a GitHub issue with your OS, app version, selected mode, expected result, actual result, and any visible error message.
