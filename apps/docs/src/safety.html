Safety model

Firebase Desk is powerful local admin software. It avoids hidden background work and keeps write actions explicit.

Mock, emulator, production

  • Mock mode uses local sample repositories.
  • Local emulator connects to Firebase Emulator Suite hosts you configure.
  • Production uses service account credentials for real Firebase projects.

Production writes

Production Firestore writes are enabled. Destructive operations require confirmation, but credentials still control what the app can do.

Credentials

Firebase Desk stores project metadata locally and uses OS-backed secure storage where available. If OS encryption is unavailable, the app warns you.

Unsigned builds

Release binaries are unsigned development builds. Verify checksums from GitHub releases before opening downloaded packages.

Mock screenshots

Docs screenshots are captured from a real mock-mode app run. They do not show production project data.
