Firebase Desk is an Electron desktop app for Firebase admin/data workflows. It gives developers a dense local workspace for Firestore, Authentication, JavaScript Query, collection jobs, Activity, and multi-environment project management.

Use the [browser demo](/firebase-desk/demo/) first if you want to try the product with sample data and no Firebase credentials.

## What it is for

- Inspect and edit Firestore data across emulator, staging, and production projects.
- Review Authentication users and custom claims.
- Run admin-style JavaScript queries against the selected connection.
- Copy, duplicate, export, import, and delete Firestore collections through background jobs.
- Keep tabs, account targets, Activity, and write context visible while switching environments.
